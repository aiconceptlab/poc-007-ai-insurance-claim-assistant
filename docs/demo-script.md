# Demo script

## Free sample (about one minute)

1. Open the app in sample/manual mode. Say: "This is an AI-assisted claim preparation concept. The example uses a synthetic image and fictional incident."
2. Select **Try sample photo**. Point to **scripted sample observations / unconfirmed**. The screen appears cracked; cause cannot be established from the photo.
3. Select **Use for asset and damage**. The next question asks for the incident date.
4. Select **Use sample incident account**. The date is 7 September 2026, in a home office, accidentally dropped from the desk.
5. Show the editable fields and **92% checklist completeness**. Expand the explanation: 8% is missing because there is no purchase receipt photo. This is not approval likelihood.
6. Correct a field. Check the review box. Download the JSON bundle or YAML draft.
7. Say: "This prepares a first draft for a person to review. It does not approve or submit claims."
